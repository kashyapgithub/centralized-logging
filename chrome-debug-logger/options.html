Central Log Capture — Settings

Log server

The local log server from the centralized-logging skill. Run python3 server.py — it defaults to http://127.0.0.1:4317. No account, no API key.

Projects

Each entry is a domain the debugger is allowed to attach to, plus a label. The label becomes app_name on every log sent to the backend — this is how two projects stay distinct even if they share a hostname (e.g. two localhost ports). For a real domain like myapp.com, subdomains are covered automatically. For local dev, include the port (e.g. localhost:3000) so different projects on different ports don't collide.
